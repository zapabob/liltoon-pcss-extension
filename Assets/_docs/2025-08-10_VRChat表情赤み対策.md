# VRChat 表情が赤くなる問題の対策メモ

- Date: 2025-08-10 JST

## 症状
- 表情切替時に顔全体が赤み／ピンク化する
- FX/Gesture のアニメでマテリアルやカラーが意図せず上書き

## 対処手順（自動＆手動）
- 自動スキャン（エディタメニューに追加予定）
  - SkinnedMeshRenderer の Element0/Element1 の割当を確認
  - 使用シェーダーが lilToon/Poiyomi で正しくインポート済みか確認
  - FX/Gesture Controller の AnimationClip で `_Color`, `_MainTex`, `_ShadeColor`, `_EmissionColor` など色系を駆動していないかチェック
  - 透明度や色キーを触るクリップを列挙し、確認ダイアログで除去候補を提示

- 手動の暫定対処
  - 顔材質の `_Color` を (1,1,1,1) へ戻す
  - `_MainTex` の sRGB / import 設定を確認
  - クリップからマテリアルプロパティのキー削除
  - lilToon のマテリアルで ToonMap / ShadeColor が不正になっていないか検証

## 実装計画
- Editor/VRChatFacialRedFixer.cs を追加
  - 選択アバター配下の SkinnedMeshRenderer とマテリアル列挙
  - AnimatorController(FX/Gesture) の全クリップ解析
  - 問題のキー（_Color, _ShadeColor, _EmissionColor, _RimColor など）を検出
  - ワンクリックで該当カーブ削除＆バックアップ
  - 既知の顔マテリアル名/Renderer名ヒューリスティクス対応

## 備考
- Modular Avatar 利用時は Merge 後の実態も確認が必要
- 変更前バックアップを必ず作成
