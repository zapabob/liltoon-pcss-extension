### 外部ライト自動配置アルゴリズム
```csharp
// 身長計算
float avatarHeight = headBone.position.y - footCenter.y;

// 最適位置計算
float baseDistance = avatarHeight * 2.5f; // 身長の2.5倍
float heightOffset = avatarHeight * 0.8f; // 身長の80%

// 4つのライト位置
positions[0] = new Vector3(0, heightOffset, baseDistance);        // メインライト
positions[1] = new Vector3(0, heightOffset, -baseDistance * 0.8f); // リムライト
positions[2] = new Vector3(-baseDistance * 0.7f, heightOffset, 0); // フィル左
positions[3] = new Vector3(baseDistance * 0.7f, heightOffset, 0);  // フィル右
```

## 📝 実装メモ

### コンパイルエラー修正 (2025-08-07 21:00:00)
**修正内容**:
1. **クラス名重複エラー**: `MenuItem`クラスを`UnifiedMenuItemData`にリネーム
2. **存在しないメソッドエラー**: 各クラスの正しいメソッド名に修正
3. **存在しないクラスエラー**: 存在しないクラスをコメントアウト
4. **Selection.assetsエラー**: `Selection.GetFiltered<Object>(SelectionMode.Assets)`に修正
5. **staticメソッド呼び出しエラー**: `UnifiedMenuSettings.ShowWindow()`を直接呼び出しに修正
6. **アクセス修飾子エラー**: `private`メソッドを`public`に変更
7. **名前空間エラー**: 完全修飾名を使用
8. **staticクラス参照エラー**: 直接クラス名を使用
9. **プロパティ名エラー**: 正しいプロパティ名に修正
10. **名前空間エラー**: `using lilToon.PCSS.Runtime;`を追加
11. **アセンブリ参照エラー**: `ModularAvatarPCSSController`の使用を一時的にコメントアウト
    - EditorスクリプトからRuntimeスクリプトの参照でアセンブリ参照の問題が発生
    - 基本的なライト機能は動作するため、PCSS設定は後で実装予定
12. **using文エラー**: `using lilToon.PCSS.Runtime.PCSSUtilities;`を削除
    - `PCSSUtilities`はクラスであり名前空間ではないため、using文で指定できない
