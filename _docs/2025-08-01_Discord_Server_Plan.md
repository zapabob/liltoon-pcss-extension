# Discordサーバー構成案

## 1. サーバー名

lilToon PCSS Extension Hub

## 2. サーバーコンセプト

- 本製品のユーザーサポート、情報交換、およびコミュニティ活動の拠点。
- 初心者から上級者まで、全てのユーザーが気軽に参加でき、有益な情報を得られる場所を目指す。
- 開発チームからの最新情報発信や、ユーザーからのフィードバック収集の場としても活用する。

## 3. チャンネル構成

### **WELCOME カテゴリ**

- `#ようこそ-rules`
    - サーバーの目的、ルール、注意事項を記載。
    - リアクションによるロール付与（後述）の案内。
- `#announcements`
    - 開発チームからの公式アナウンス（アップデート情報、メンテナンス通知など）。
    - 書き込みは管理者のみ。
- `#roadmap`
    - 製品の今後の開発ロードマップを公開。ユーザーからの期待感を醸成する。

### **COMMUNITY カテゴリ**

- `#general-雑談`
    - 製品に関する雑談や一般的な会話を行うチャンネル。
- `#q-a-質問`
    - 製品の導入や使い方に関する質問を受け付けるチャンネル。
- `#showcase-作品紹介`
    - ユーザーが本製品を使用して制作したアバターや写真、動画を共有するチャンネル。
- `#feedback-要望`
    - 製品に対する機能要望や改善案を受け付けるチャンネル。

### **SUPPORT カテゴリ**

- `#bug-reports-不具合報告`
    - 製品の不具合を報告する専門チャンネル。
    - 報告用のテンプレートを用意し、ユーザーがスムーズに報告できるようにする。
- `#known-issues-既知の問題`
    - 現在開発チームが把握している既知の不具合や、その回避策をリストアップする。

### **INTERNATIONAL カテゴリ**

- `#english-chat`
    - 英語話者向けの雑談・質問チャンネル。

## 4. ロール設計

- **@Admin:** サーバー管理者（開発チーム）
- **@Supporter:** ユーザーサポートを行うボランティアスタッフ（希望者制）
- **@User:** 一般ユーザー（初期ロール）
- **@日本語 (JP):** 日本語話者（ロール選択制）
- **@English (EN):** 英語話者（ロール選択制）

## 5. Botの導入

- **Carl-bot:** リアクションによるロール付与、ログ管理、モデレーション機能。
- **DeepL Bot:** 国際チャンネルでの翻訳補助。

## 6. 基本ルール案

1.  すべてのユーザーに対し、敬意をもって接してください。
2.  ハラスメント、スパム、不適切なコンテンツの投稿を禁止します。
3.  技術的な質問は、まず `#q-a-質問` チャンネルでお願いします。
4.  不具合を見つけた場合は、`#bug-reports-不具合報告` にテンプレートを使用して報告してください。
5.  サーバーの招待リンクを無断で外部に公開しないでください。

## 7. 運用計画

- **初期段階:** 開発チームが中心となって、アナウンス、質問への回答、フィードバックの確認を行う。
- **活性化段階:** コミュニティが活発になってきたら、信頼できるユーザーに `@Supporter` ロールを付与し、コミュニティ主導でのサポート体制を構築する。
- **イベント:** 定期的に、ShowcaseコンテストやQ&Aセッションなどのイベントを開催し、コミュニティの活性化を図る。
