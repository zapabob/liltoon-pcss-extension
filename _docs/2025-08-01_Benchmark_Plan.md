# ベンチマーク計測セットアップ計画書

## 1. 目的

- lilToon PCSS Extension (v2.4.0) と nHaruka PCSSforVRC のパフォーマンスを客観的に比較し、本製品の技術的優位性を実証するデータを取得する。
- 取得したデータは、技術ブログ記事やSNSでの広報活動に活用する。

## 2. 比較対象

- **本製品:** lilToon PCSS Extension v2.4.0 (最適化版PCSSを有効化)
- **競合製品:** nHaruka PCSSforVRC (BOOTHで販売されている最新版)

## 3. テスト環境

- **Unityバージョン:** 2022.3.6f1
- **VRChat SDK:** Avatars 3.5.1
- **lilToonバージョン:** 2.1.4
- **Modular Avatarバージョン:** 1.12.5
- **ハードウェア:** 
    - CPU: Intel Core i7-13700K
    - GPU: NVIDIA GeForce RTX 4080
    - RAM: 32GB

## 4. テストシナリオ

### 4.1. 使用アバター

- **モデル:**桔梗 (Kikyo) by ポンデロニウム研究所 (VRChatで広く普及しており、比較対象として中立的かつ一般的であるため)
- **設定:**
    - **Avatar A (本製品):** 桔梗に本製品の「ワンクリック・セットアップ」を適用し、「パフォーマンス」プリセットを適用した状態。
    - **Avatar B (競合製品):** 桔梗にnHaruka製品の公式手順書通りにセットアップを適用した状態。
    - **Avatar C (コントロール):** シェーダーはlilToonのまま、PCSS機能を適用しない状態。

### 4.2. 使用ワールド

- **ワールド:** VRChat Home (公式ワールドであり、ライティング環境が安定しているため)
- **条件:**
    - 1人のプレイヤーがワールドに存在する状態 (Solo)
    - 10人のプレイヤー（Avatar A, B, Cのクローンを混在）が存在する状態 (Group)

### 4.3. 計測項目とツール

- **計測ツール:**
    - **Unity Profiler:** CPU使用率、GPU使用率、レンダリング関連のパフォーマンス詳細を計測。
    - **VRChat内デバッグメニュー:** 平均フレームレート (FPS) と VRAM使用量を計測。
    - **エディタスクリプト:** シェーダーのインポートおよびコンパイルにかかる時間を計測。

- **計測項目:**
    1.  **FPS (Frames Per Second):** 90秒間定点観測した際の平均、最大、最小FPS。
    2.  **VRAM使用量:** アバター表示時のVRAM使用量。
    3.  **SetPass Calls (Draw Calls):** Unity Profilerで計測。レンダリング負荷の主要因。
    4.  **シェーダーコンパイル時間:** シェーダーが初めてインポート・コンパイルされる際の時間。

## 5. 手順

1.  Unityプロジェクトを新規作成し、テスト環境を構築する。
2.  桔梗アバターをインポートし、Avatar A, B, Cの3つのプレハブを作成する。
3.  VRChat Homeワールドに各アバターを配置したテストシーンを作成する (Solo用、Group用)。
4.  ビルドしたクライアントを起動し、各シナリオで計測項目を3回ずつ記録する。
5.  計測結果の平均値を算出し、グラフ化する。
6.  結果を基に、ブログ記事のドラフトを作成する。
