# 2025-08-11 VRChat事前バリデーション 強化修正

## 目的
VRChat SDK Validator の `IndexOutOfRangeException` 回避と安定化。

## 実装概要
- `Editor/VRChatPreValidation.cs` を強化。
  - 各Playable Layerの `AnimatorControllerLayer.stateMachine` を必ず確保。
  - ステートが0件の場合は `Idle` を作成し、`defaultState` を設定。
  - `defaultState.motion` が null の場合に備え、コントローラに内包する空クリップ `PCSS_EmptyClip` を生成して割当。
  - すべてのステートを走査し、モーション皆無の場合は `defaultState` に空クリップを割当。
  - ExpressionParameters は null/重複/無名を除去し、16件に制限。`defaultValue` を 0..1 に正規化。
  - Missing Script は `GameObjectUtility.RemoveMonoBehavioursWithMissingScript` で安全に除去。

## 期待効果
- SDK内部のレイヤー/ステート走査時に配列外参照が発生しない。
- 無モーション層でも必ず `defaultState` と `motion` を保証。

## 実行手順
1. アバタールートを選択
2. メニュー: `Tools/lilToon-PCSS-Extension/VRChat/事前バリデーション実行`
3. SDK Validator/Upload を再実行

## 備考
- `lilToon` の空JSON起因の初期化例外は、別途 `LilToonPCSSExtensionInitializer` の修復機構で `{}` を書込。
