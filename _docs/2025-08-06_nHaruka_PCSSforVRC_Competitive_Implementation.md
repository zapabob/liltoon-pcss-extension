# nHaruka PCSSforVRC 競合実装レポート

## 概要

nHaruka氏の「PCSSforVRC」を競合製品として分析し、それを上回る機能性と利便性を持つPCSS（Percentage-Closer Soft Shadows）拡張機能をlilToon向けに実装した。

## 実装内容

### 1. アバター追従ライトの自動セットアップと調整

- **機能:** `OneClickSetupWizard`に、アバターの頭部に追従するスポットライトを自動で生成・設定する機能を追加。
- **詳細:**
    - 既存のPCSS用ライトを検知して重複を回避。
    - 生成されるライトは、対象アバターのレイヤーのみを照らし、影のみを生成するように設定。
    - VRChat環境向けに`VRCLight`コンポーネントを自動で追加。
    - ウィザード上でライトの角度、範囲、強さ、色をリアルタイムでプレビュー・調整できるUIを実装。

### 2. 高度なマスク設定機能

- **機能:** `CastMask`（影を落とす側）と`ReceiveMask`（影を受ける側）を個別のテクスチャで設定できるよう、シェーダーとウィザードを拡張。
- **詳細:**
    - シェーダーの`_ShadowMaskTex`プロパティを拡張し、Rチャンネルを`CastMask`、Gチャンネルを`ReceiveMask`として利用。
    - ウィザードに、それぞれのマスクテクスチャを割り当てるためのUIを追加。
    - 設定された2つのマスクテクスチャを、ウィザードが1つの`ShadowMaskTex`に自動で結合してマテリアルに適用するロジックを実装。

### 3. パフォーマンス品質プリセット

- **機能:** ウィザードに「低」「中」「高」「Ultra」の4段階の品質プリセットを追加。
- **詳細:**
    - ユーザーがドロップダウンメニューからプリセットを選択するだけで、PCSSの品質（`_PCSSQualityLevel`）とサンプル数（`_LocalPCSSSamples`）が自動的に設定される。
    - これにより、専門知識がないユーザーでも、パフォーマンスと品質のバランスを簡単に調整可能。

## 競合優位性

- **高いカスタマイズ性:** ライト設定のリアルタイム調整や、`CastMask`/`ReceiveMask`の個別設定により、nHaruka氏の実装よりも詳細な影のコントロールが可能。
- **優れた利便性:** `OneClickSetupWizard`によるガイド付きセットアップと品質プリセットにより、初心者でも簡単に最適な設定を導入可能。
- **堅牢な実装:** 既存設定の検知や、VRChat環境への自動対応など、安定性と信頼性を高めるための工夫を多数導入。
