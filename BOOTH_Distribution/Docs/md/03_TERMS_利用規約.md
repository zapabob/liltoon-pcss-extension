# lilToon PCSS Studio for VRChat 利用規約

本規約は、BOOTH等で配布される lilToon PCSS Studio for VRChat の利用条件をまとめたものです。

## 利用できること

- 個人利用
- 商用利用アバターへの導入
- VRChatへのアップロード
- 購入者本人のプロジェクト内での改変
- 動画、配信、スクリーンショットでの利用

## 禁止事項

- 本パッケージ一式の再配布、再販売、共有
- 改変した本パッケージ一式の再配布、再販売、共有
- 第三者が本商品を入手できる形でのアップロード
- 公序良俗に反する用途での利用
- VRChat、lilToon、Modular Avatar等の各規約に反する用途での利用

同梱されるソースコード部分にMIT Licenseが明示されている場合、その範囲には `LICENSE` の内容が優先されます。

BOOTH販売物として同梱されるドキュメント、プリセット、販売用構成、サポート提供は本規約の対象です。

## 免責

本パッケージの利用により発生したプロジェクト破損、アップロード失敗、アバター表示崩れ、規約違反、その他の損害について、作者は責任を負いません。導入前に必ずバックアップを作成してください。

## サポート範囲

導入手順、Unity上の明確なエラー、PCSS Hubの動作不良を中心に対応します。個別アバターの造形、衣装改変、外部ツール固有の不具合、VRChat側の仕様変更に起因する問題は、対応できない場合があります。
