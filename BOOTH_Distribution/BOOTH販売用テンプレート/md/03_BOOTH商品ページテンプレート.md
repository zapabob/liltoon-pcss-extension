# BOOTH商品ページテンプレート

## 商品名

lilToon PCSS Studio for VRChat

## サブタイトル

PC向けVRChatアバターの影・艶・血色感をまとめて整えるlilToon用Editor拡張

## 短い説明

`lilToon PCSS Studio for VRChat` は、PC向けVRChatアバターのlilToonマテリアルに、柔らかいPCSS風の影、控えめな艶、撮影向けの温かい血色感をまとめて設定するUnity Editor拡張です。AAOとの併用を考え、標準ではアバター内に不要なUnity Lightを残しにくい `0 Lights` ワークフローを用意しています。

## 主な機能

- PCSS Hubによる一括セットアップ
- lilToonマテリアルのPCSS化
- AAO Performance Safe (0 Lights) ワークフロー
- Dewy Skin Gloss / うるみ艶肌
- Soft Flush Skin / ほのか上気肌
- Excited Tone / 高揚発色
- Legacy PCSS v2.2.0 Intake
- Editor用Camera Depth Preview
- Modular Avatar連携メニュー
- VRC Light Volumes連携設定

## 高揚発色 / Excited Toneについて

成人寄りの表現名は使わず、運動後・ライブ照明・撮影用の温かい血色感として扱える健全な色調プリセットです。顔・肌マテリアルには温かい発色、控えめな艶、柔らかい影をまとめて適用し、衣装や髪へ強く色が乗らないよう調整しています。

## 対応環境

- Unity 2022.3.22f1
- VRChat Avatars SDK 3.10.3以降
- lilToon 2.3.2以降
- Modular Avatar 1.17.1以降
- VRC Light Volumes 2.1.3以降は任意

## 注意事項

- PC向けVRChatアバター用です。
- Quest/Android向けのPCSS表現には対応していません。
- VRChat、lilToon、Modular Avatar、Avatar Optimizer、VRC Light Volumesは同梱していません。
- 導入後の見た目はアバターのUV、マテリアル構成、ライト環境によって変わります。
- VeryPoorが残る場合は、三角形数、Skinned Mesh Renderer数、PhysBone、Contact、Material Slotなどアバター本体の要因も確認してください。
