## 🚀 Installation

### VPM Installation (Recommended)
1. Open VRChat Creator Companion
2. Add repository: `https://github.com/zapabob/liltoon-pcss-extension`
3. Install `com.liltoon.pcss-extension` package
4. Follow the setup wizard

### Manual Installation
1. Download the Unity package from releases
2. Import into your Unity project
3. Run the compatibility checker
4. Configure your avatar settings
